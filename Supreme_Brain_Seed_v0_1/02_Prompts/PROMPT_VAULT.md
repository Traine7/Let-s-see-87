# Prompt Vault

## 1. PRD Builder Prompt
Create a Product Requirements Document for this project. Include problem statement, target users, core features, user journeys, tech preferences, accessibility needs, data model, risks, and MVP scope. Keep it build-ready.

## 2. Feature Breakdown Prompt
Divide the project into features and each feature into small tasks. For every task include purpose, inputs, outputs, dependencies, and acceptance criteria.

## 3. Master Prompt Builder
Create a master prompt document for an AI coding assistant. Include project overview, strict instructions, tech stack, style guidelines, file structure, output format, testing requirements, and what not to do.

## 4. Screenshot Extraction Prompt
Analyze every visible element in this image. Extract text, infer the workflow, identify the project branch it belongs to, create reusable prompts from it, and list any privacy or verification concerns.

## 5. Story of Pi Continuation Prompt
Continue the Story of Pi in full continuity. Preserve Pi Nakamura, Echo, Cold, Sol, the Bridge, learning milestones, dry wit, scarlet/gold Codex identity, and the core philosophy Null -> Still -> Anti-Anti-Null -> Player Choice. Do not skip chapters. Map scenes to GUI/game mechanics when useful.

## 6. GUI Mapping Prompt
Turn this narrative or project idea into screens, components, states, buttons, data objects, accessibility requirements, and code modules. Include mobile and desktop considerations.

## 7. Real Estate War-Room Prompt
Evaluate this property or housing idea through VA loan strategy, build feasibility, zoning, accessibility, cash flow, long-term family compound potential, refinance options, risk, and negotiation posture.

## 8. Finance/FNA Prompt
Build a financial needs analysis using Primerica-style education logic. Include debts, interest rates, minimum payments, payoff ordering, cash flow redirection, emergency reserve, mortgage strategy, and client-first negotiation framing.

## 9. Leadership Doctrine Prompt
Convert this idea into leadership thesis material. Integrate Marine Corps experience, Primerica-style education, Maxwell, Covey, Goleman, Drucker, Collins, Art Williams, Kiyosaki, Gerber, and Carnegie where appropriate.

## 10. Language Scroll Prompt
Create a Spanish/French/Bemba side-by-side lesson with vocabulary, pronunciation, conjugation, usage examples, micro-drills, and tracker fields.
