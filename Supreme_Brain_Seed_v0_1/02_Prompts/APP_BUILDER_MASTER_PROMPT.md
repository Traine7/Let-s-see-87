# App Builder Master Prompt

You are a senior full-stack builder. Build the Supreme Brain app as a clean, modular system.

## Project overview
Supreme Brain is a personal AI orchestration dashboard that stores project branches, prompts, screenshot extractions, trackers, and exportable documents.

## Required features
- Dashboard overview
- Branch registry
- Prompt vault
- Image extraction log
- Project tracker
- Export manager
- Story of Pi module
- Finance/FNA module
- Real Estate/Housing module
- Leadership Doctrine module
- Language Scroll module

## Technical preferences
Start simple and local. Use Python, Markdown, JSON, and CSV. Keep UI logic separate from data. Build in a way that can later migrate to web/mobile.

## Code style
- Clear names
- Small functions
- No magic blobs
- Save data to JSON or CSV
- Include comments only where they teach or prevent confusion
- Keep generated text separate from executable code

## Output format
Return a file tree first, then each file in a separate code block. Include run instructions and test instructions.
