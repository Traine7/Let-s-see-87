# Image-to-Prompt Cards

## Card: Documentation Before Code
Use when building any app.
Prompt: “Before writing code, produce the PRD, feature breakdown, master prompt, tech stack, code style rules, file tree, and test plan.”

## Card: Bed Command Station UX
Prompt: “Design this interface for a user operating from bed with wheelchair mobility, iPad/iPhone access, possible Apple Vision Pro use, and limited desire to physically move between devices.”

## Card: Small Business Menu Digitizer
Prompt: “Extract a restaurant menu from an image into clean categories, items, prices, add-ons, business details, and a simple ordering-page layout.”

## Card: Debt Efficiency Calculator
Prompt: “Create a spreadsheet or Python calculator that ranks debts by balance, APR, minimum payment, debt efficiency, extra payment allocation, and projected cash-flow impact.”

## Card: AI Tool Bench
Prompt: “Create a tool tier list not by hype, but by Supreme Brain job role: writing, coding, research, spreadsheet, visual design, automation, and orchestration.”
