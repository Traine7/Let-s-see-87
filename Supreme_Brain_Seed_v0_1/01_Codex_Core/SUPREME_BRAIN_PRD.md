# Supreme Brain Product Requirements Document

## Product name
Supreme Brain

## Product purpose
A personal AI command system that turns conversations, screenshots, documents, ideas, project plans, research, prompts, and app concepts into a living operational brain.

## Core problem statement
The user has many interconnected projects spread across chats, screenshots, files, websites, and ideas. The problem is not lack of ideas. The problem is fragmentation: story work sits apart from GUI work, financial planning apart from real estate strategy, leadership doctrine apart from language learning, and screenshots often die as inspiration instead of becoming build instructions.

## Target users
Primary: Cpl Tremain A. Wade Jr., USMC (Ret.), as orchestrator.  
Secondary future users: veterans, disabled creators, work-from-home parents, AI-powered solopreneurs, learners building through story/game interfaces.

## Non-negotiable use cases
1. Store and summarize project branches.
2. Convert images into structured prompts and requirements.
3. Maintain a project tracker with status, next action, and export readiness.
4. Generate app-building documents: PRD, feature breakdown, master prompt, tech stack, UI/UX notes.
5. Support Story of Pi as both manuscript and playable GUI/game curriculum.
6. Support leadership doctrine, finance/FNA, housing/real estate, dreams board, and language branches.
7. Provide command prompts for multiple AI systems.

## Success criteria
- A new AI system can read the bundle and understand the mission in minutes.
- A builder can use the PRD and feature breakdown to begin coding.
- A future Markdown or DOCX mega-file can be generated from this folder.
- Every screenshot becomes either a requirement, prompt, warning, or inspiration node.

## Initial tech preference
- Markdown for durable writing.
- JSON for branch registry.
- CSV for trackers.
- Python for orchestration and prototypes.
- Tkinter or web UI later for accessible local interface.
- Future connectors: Canva/Figma for visuals, GitHub for repository, spreadsheets for trackers, AI tools for role-based execution.
