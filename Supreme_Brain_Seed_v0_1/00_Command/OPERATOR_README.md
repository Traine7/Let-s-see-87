# Operator README

## Mission
Build a personal AI orchestration system that gathers, organizes, prompts, retrieves, and helps execute all major life/project branches: Story of Pi, GUI/game systems, leadership doctrine, housing and real estate strategy, finance/FNA planning, language immersion, health/adaptive systems, dreams boards, and AI business automation.

## Operating stance
- Preserve continuity.
- Do not flatten rich ideas into shallow summaries.
- Convert screenshots, notes, chats, and links into usable project assets.
- Track what exists, what is planned, and what needs verification.
- Separate imagination from execution, but allow them to work together.
- When building apps, move from PRD -> feature breakdown -> master prompt -> code scaffold -> testable artifact.

## First law
Never pretend the archive is complete when it is only seeded. Mark gaps honestly and keep building.
