# Accessibility Doctrine

## Core Belief
Accessibility is not a patch. It is the hinge.

## Design Priorities
- Voice and text interaction
- Cognitive support
- Step-by-step guidance
- Large readable UI
- Adjustable pacing
- Non-timed learning
- Power chair and bed-use awareness
- Cross-device continuity

## Identity Principle
The user is not a patient inside software. The user is a warrior inside a command system.
