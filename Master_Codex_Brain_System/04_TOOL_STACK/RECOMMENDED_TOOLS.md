# Recommended Tools

## Primary Brain
Obsidian

Why:
- Local Markdown files
- Graph view
- Canvas
- Portable
- Plugins
- Works well for a long-term Codex vault

## Visual Research Layer
Heptabase

Why:
- Whiteboards
- Cards
- Visual research
- Good for complex learning topics

## Private Object Database Layer
Anytype

Why:
- Offline-first
- Local-first
- Object-based
- Good for private structured knowledge

## AI Research Layer
NotebookLM or equivalent source-grounded AI tool

Why:
- Useful for asking questions across uploaded sources
- Better for citation-grounded summaries

## Automation Layer
n8n

Why:
- Visual automation workflows
- Connects tools, APIs, and AI systems
