# Offer Creation Framework

## Use When
You know the problem and need to shape a paid offer.

## Prompt
Create a high-converting offer for [PROBLEM].

Include:
- Ideal customer profile
- Clear value proposition
- Low, mid, and premium pricing tiers
- Guarantee and risk reversal
- Why this beats competitors
- Landing page structure

## Codex Use
Use this to define the first paid version of the AI coach, course, consulting package, or app beta.
